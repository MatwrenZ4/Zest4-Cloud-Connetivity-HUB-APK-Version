Call recording

Would you like all calls to be recorded automatically?

Important — you must notify callers

Under UK law, callers must be informed that their call may be recorded. Include a notification in each auto attendant's welcome message (or voicemail greeting, if you're not using an auto attendant) when callers first connect.

For example:
"Please note that calls may be recorded for training and quality purposes."

You can update this on the Auto attendant step — use the Back button if you'd like to update it now.
